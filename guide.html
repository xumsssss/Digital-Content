PRODUCTION GUIDE

조별 제작 가이드

이 사이트는 전체 과목 → 장소 → 제품 3단계입니다. 전체 과목 페이지는 과목 담당자가, 장소와 제품 페이지는 각자(조별) 만듭니다.

1. 통일하는 것 / 자유로운 것

통일 : ① 글꼴(Pretendard, 고정) ② 페이지 구성 요소(섹션 순서와 구조)
자유 : 색, 모서리, 굵기, 자간, 이미지, 배경 패턴, 추가 CSS 등 모든 디자인 무드

2. 폴더 구조 — 내 폴더 안만 수정

index.html                 전체 과목 홈 (과목 담당자)
sitemap.js                 장소 목록 (과목 담당자)
course/                    과목 홈의 내용·디자인 (과목 담당자)
shared/                    ★ 공통 모듈 — 수정 금지 (글꼴·구성 요소·3D 라이브러리)
places/
  myeongdong/              ← 1조 폴더 (이 안만 수정)
    index.html             장소 페이지 (수정 불필요)
    place.js               장소 데이터: 세계관·특징·지도·제품 목록
    place.css              장소 디자인 무드 (색 등 변수)
    images/hero.webp       장소 첫화면 이미지
    products/
      fold-1/
        index.html         (수정 불필요)
        product.js         제품 상세 데이터 (7단 구성)
        product.css        이 제품만의 추가 디자인 (선택)
        images/            hero.webp, design-1.webp …
        models/            *.glb (선택)
templates/                 새 장소/제품을 만들 때 복사할 템플릿
tools/embed-models.html    3D(GLB)를 오프라인용으로 변환하는 도구

3. 제품 페이지 7단 구성 (product.js)

  1. 제품 컨셉 및 한 문장 설명 — oneLine, concept, image
  2. 페르소나와 해결하고자 하는 문제 — persona, problem
  3. 핵심 기능과 작동 원리 — functions, principle
  4. 입력 정보 → AI 판단 → 물리적 반응 — flow
  5. 사용 시나리오 — scenario (스크롤에 따라 모니터가 변함)
  6. 제품 디자인 이미지 — gallery (+ 선택: model 3D 탐색기)
  7. 주요 사양 및 소재 — specs, materials

비워 둔 항목은 페이지에 “준비 중”으로 보이므로 작성 현황을 바로 알 수 있습니다. 항목별 작성 예시는 templates/product/product.js 를 보세요.

4. 디자인 무드 바꾸기 (place.css)

장소 폴더의 place.css 맨 위 변수만 바꾸면 장소 페이지와 그 장소의 모든 제품 페이지가 함께 바뀝니다.

:root {
  --bg: #0a0a0f;      /* 배경 */          --ink: #f4f4f8;     /* 글자색 */
  --bg2: #13131c;     /* 카드/패널 배경 */ --mute: #8b8ba0;    /* 보조 글자색 */
  --accent: #c6ff3d;  /* 포인트 컬러 */    --line: #26263a;    /* 구분선 */
  --radius: 0px;      /* 모서리 */         --fw-title: 800;    /* 제목 굵기 */
}

변수로 부족하면 place.css 아래쪽(또는 제품별 product.css)에 자유롭게 CSS를 추가하세요. 구성 요소의 클래스 이름은 shared/components.css 에서 확인할 수 있습니다. 글꼴(font-family)은 바꾸지 않습니다.

5. 이미지 규칙

  • WebP 권장, 가로 1600~2400px, 파일당 300KB 이하
  • 경로는 항상 해당 폴더 기준 상대 경로: images/hero.webp
  • 파일이 아직 없으면 회색 플레이스홀더가 대신 보입니다 (파일을 넣으면 자동 교체)

6. 3D 모델(GLB)과 오프라인

  • 모든 요소(글꼴, 3D 뷰어, 스크립트)는 사이트 폴더 안에 포함되어 있어 인터넷 없이 동작합니다.
  • 웹서버·호스팅에서는 models/*.glb 경로만 지정하면 됩니다.
  • index.html 을 더블클릭(file://)으로 열 때는 브라우저 보안 때문에 GLB를 직접 읽지 못합니다. tools/embed-models.html 로 models.embed.js 를 만들어 제품 폴더에 넣고, 제품 index.html 의 해당 줄 주석을 해제하세요.
  • 전시 현장에서는 폴더를 USB/노트북에 통째로 복사해 열거나, 노트북에서 간단한 로컬 서버(python -m http.server)로 띄우는 것을 권장합니다.

7. 제출 체크리스트

  • □ place.js 의 world / features / map / products 모두 작성
  • □ 제품마다 product.js 7단 항목 작성 (“준비 중” 표시가 남지 않는지 확인)
  • □ 이미지 경로의 파일명 일치 여부 (플레이스홀더가 남지 않는지)
  • □ 3D 사용 시 models.embed.js 생성 및 주석 해제
  • □ 인터넷을 끄고 열어서 동작 확인
